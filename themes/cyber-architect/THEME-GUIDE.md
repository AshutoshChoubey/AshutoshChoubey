# Cyber-Architect Theme (Midnight Cyan Edition)

The **Cyber-Architect** theme is a high-contrast engineering aesthetic built for software architects and senior engineers.

## Visual Tokens & Palette
- **Obsidian Midnight Base:** `#060B17` to `#0B172E`
- **Primary Ambient Glow:** Electric Cyan `#00C9FF` (22% opacity) & Cobalt Blue `#1E40AF` (32% opacity)
- **Grid Pattern:** `#38BDF8` @ 5% opacity, 32px × 32px pitch
- **Radiant Perimeter Trace:** Emerald Green `#34D399` → Electric Cyan `#00C9FF` → Sky Blue `#38BDF8` → Crimson `#F43F5E`
- **Flowing Wave Streams:** Continuous dual horizontal waves in Cyan `#00C9FF` and Emerald `#34D399`
- **Embers / Sparks:** Rising particles in Emerald, Ruby, Electric Cyan, and Golden Amber

## Key Features
- Dynamic animated SVG terminal CLI with live simulated typing.
- 4-pillar Core Technology layout (Angular, TypeScript, RxJS, NgRx).
- 3-node Agentic AI Orchestration cycle (Plan → Act → Reflect) with moving arrows and feedback loop.
- 100% self-contained assets in `./assets/` with valid SVG XML and no external dependencies.
